# SFTP MCP

Transfers files over SFTP. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/sftp-mcp

Installs from the Camillia hub as `sftp-mcp-3a3860`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
